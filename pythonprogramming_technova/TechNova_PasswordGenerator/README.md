# Password Generator

## About
A beginner-friendly Python program that generates a password using letters, numbers, and symbols. The user chooses the password length.

## Features
- Lets the user choose the password length
- Includes uppercase and lowercase letters
- Includes numbers and symbols
- Displays the generated password
- Requires a minimum length of 3 characters

## Concepts Used
- Variables and user input
- Conditions and loops
- Strings and lists
- Python modules: `random` and `string`

## How to Run
Make sure Python is installed, open a terminal in this folder, and run:

```bash
python main.py
```
