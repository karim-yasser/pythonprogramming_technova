# TechNova Python Programming Internship Projects

This repository contains three beginner-level Python projects created for practice during the TechNova Python Programming Internship.

## Projects

1. **Password Generator** — creates passwords containing letters, numbers, and symbols.
   - [Project README](TechNova_PasswordGenerator/README.md)
2. **Number Guessing Game** — lets the player guess a random number and provides higher/lower hints.
   - [Project README](TechNova_NumberGuessingGame/README.md)
3. **File Organizer** — sorts files into folders based on their extensions.
   - [Project README](TechNova_FileOrganizer/README.md)

## Requirements
- Python 3
- A code editor or terminal

## How to Run
Open the folder for the project you want to run and follow the instructions in that project's README.

## Purpose
These projects practice basic Python concepts, including variables, conditions, loops, modules, and file handling.
