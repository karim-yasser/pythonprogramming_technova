# Number Guessing Game

## About
A simple console game where the program chooses a random number from 1 to 100. The player keeps guessing until the correct number is found.

## Features
- Generates a random number
- Gives higher/lower hints
- Counts the number of attempts
- Ends when the player guesses correctly

## Concepts Used
- Variables and user input
- Random numbers with `random`
- `while` loops
- `if` and `elif` conditions
- Attempt counting and `break`

## How to Run
Make sure Python is installed, open a terminal in this folder, and run:

```bash
python main.py
```
